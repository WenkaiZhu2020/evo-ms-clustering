# Extracted Data

Normalized Soot/Shimple extraction outputs belong here. These CSVs are generated by the Java extractor and are used as Stage 1 pipeline inputs.

Each subject directory contains:

- `class_nodes.csv`
- `structural_dependencies.csv`
- `ssa_flow_edges.csv`

Do not put generated experiment result tables here; those belong under `results/<subject>/<stage>/`.
