
# Pre-experiment Findings

This folder stores the active Stage 1 research reports.

Generated CSV results are under:

```text
results/pre_experiment/subjects/<subject>/
```

Technical implementation notes remain under:

```text
docs/stage1/
```

## Findings

| File                                | Purpose                                                      |
| ----------------------------------- | ------------------------------------------------------------ |
| `test_case_selection_summary.md` | explains the roles of the selected subject systems |
| `ssa_calibration_notes.md` | records constrained DayTrader calibration and the frozen Leiden profiles |
| `xerces-j_sensitivity_notes.md` | records the larger-scale Xerces-J sensitivity findings |

## Scope

These reports cover:

* class-level extraction;
* `G_raw` and `G_ssa` construction;
* SSA impact analysis;
* constrained Leiden calibration;
* formal Stage 1 baseline profiles.

The cross-subject Stage 1 interpretation is in
`docs/stage1/findings/cross_case_summary.md`.
