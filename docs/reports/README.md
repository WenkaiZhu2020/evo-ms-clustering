# Reports

This folder contains human-readable experiment notes and Stage 1 summaries.

Generated CSV evidence remains under `results/<subject>/`. Normalized extraction inputs remain under `data/extracted/<subject>/`.

## Current Reports

- `stage1_cross_case_summary.md`: cross-subject Stage 1 summary for JPetStore, DayTrader, and Xerces-J.
- `test_case_selection_summary.md`: rationale for the current subject set.
- `ssa_weight_adjustment_log.md`: pointer to current SSA weight and sensitivity evidence.
- `xerces-j_extraction_notes.md`: extraction scope and build notes for Xerces-J.
- `xerces-j_stage1_report.md`: Stage 1 analysis report for Xerces-J.

## Report Boundary

Reports should summarize committed evidence and source paths. They should not contain task prompts, future work instructions, or generated-to-self checklists.
