# Legacy selected-semantic statistics

`formal_statistical_tests_pre_active_stage2_profile.csv` is a byte-preserved
copy of the pre-correction formal table. Its selected-`f_semantic` rows used an
earlier saved Stage 2 representative and are historical evidence only.

Current Section 4.3 reporting must use the parent directory's
`formal_statistical_tests.csv` and `formal_selected_fsemantic_per_seed.csv`,
which use the frozen 5% modularity-band Stage 2 operating profile. The legacy
file must not be loaded by current report generation.

`formal_summary_pre_reporting_contract.csv` preserves the former Stage 3-only
descriptive summary, including front-size and front-range rows. Those values
remain valid historical/descriptive evidence; the current parent
`formal_summary.csv` is scoped to the two-metric Stage 2/Stage 3 reporting
contract and includes both stages' sample standard deviations and IQRs.
