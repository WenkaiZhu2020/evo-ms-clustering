# Accepted paired artifact scope

`paired_per_seed.csv` remains the canonical, accepted source for the Stage 2
and Stage 3 projected-Hypervolume pairs. Its historical selected-semantic
columns record the representative available when that file was first produced;
they are not current Section 4.3 selected-`f_semantic` inputs.

Current selected-`f_semantic` pairs are recomputed from the active Stage 2 5%
modularity-band profile and final Stage 3 selected solutions, and are stored in
`../formal_statistics/formal_selected_fsemantic_per_seed.csv`.
