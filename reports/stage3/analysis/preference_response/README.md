# Final preference-response analysis

This is a post-hoc exploratory analysis of saved Stage 2 and final Stage 3
retained fronts. It reports conservative selection, modularity-budget
balance response, final semantic-budget response, availability,
conditional summaries, realised modularity loss, secondary structural
costs, partition stability, and valid DayTrader external metrics.

The 5% profile is an illustrative operating point, not a universal
threshold. JPetStore and Xerces external reference metrics are unavailable.
The authoritative DayTrader MoJoFM mean is 23.550724637681.
