# Final Stage 3 report architecture

This directory is the canonical thesis-facing report root for the final
Declaration + Method Body experiment.

- `tables/`: compact scientific tables and subject summaries;
- `figures/`: publication-ready figures and figure provenance;
- `analysis/stage2_vs_stage3/`: paired Stage 2 versus final Stage 3 analysis;
- `analysis/preference_response/`: post-hoc exploratory preference analysis;
- `provenance/`: identities, artifact hashes, manifests, and source records;
- `validation/`: reproducibility and acceptance checks.

Process logs, temporary locks, and raw audit dumps do not belong in this
canonical tree.
